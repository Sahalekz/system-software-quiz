# System Software Quiz

An interactive web-based quiz application covering System Software concepts:
- Operating Systems & Types
- Booting Process (BIOS/UEFI, POST, Bootloaders, Kernel Initialization)
- File Systems (NTFS, ext4, APFS, Journaling, Extents)
- Device Drivers & Hardware Interfaces

## Features
- 19 categorized questions across Easy, Medium, and Hard difficulty tiers
- Immediate feedback with detailed explanations and references
- Interactive progress meter and real-time score tracking
- Performance breakdown by difficulty level
- Sharable score summary generator and question review filters
- Responsive design with dark/light mode support

## Local Preview
Simply open `index.html` in any web browser, or serve it locally using:
```bash
# Python
python -m http.server 3000

# or Node / npx
npx serve .
```
